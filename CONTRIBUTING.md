# Contributing to docker-keepalived

The [shared rules](https://github.com/cplieger/.github/blob/main/CONTRIBUTING.md) for commits, releases, synced files and checks apply here.

## Rules

A change to the files in `patches/` also changes these places, which no check covers:

- The README's License section names each checked-in patch, because its source offer must list the complete source of the shipped binary.
- The README's Who it is for, Security and Documentation sections, `docs/hardening.md` and `docs/how-it-works.md` say what the current patch does or that the binary carries it.
